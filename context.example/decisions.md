# Decisions for <project>

Dated, append-only. Record the why at decision time, not later.

Format: `- <YYYY-MM-DD> — <decision> — <why> (<who>) — revisit when: <trigger>`

`<who>` names the decider. For my own call, give my name, and quote my words when they settle
it. When an agent inferred the decision, write `<agent>'s reading of <what I said>`. To change a
decision, add an entry that cites the one it replaces. For a wrong fact, add an entry that
starts with `Correction:`. Never edit or delete an entry.
